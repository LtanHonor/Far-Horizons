# FH Gamemaster Tools

Gamemaster tools for creating and running a game of Far Horizons.

These python utilities are designed to replace the old bash scripts in ../bash.
They wire together FH's various programs and provide simpler interface for a GM
running a game.


**Install Depedencies**

You must have python 3 installed on your system.

Debian/Ubuntu:

```
apt install poppler-utils ps2pdf  python3-dateutil
```

Fedora:

```
dnf install poppler-utils ghostscript python3-dateutil
```

macOS:

```
brew install ghostscript poppler
python3 -m pip install -r pyrequirements.txt
```

**Note:** google/gmail integration is currently not working as the code
relies on broken google apis.


```
farhorizons.yml   - configure your fh games here see farhorizons.yml.sample
                    generally I would put this in the game data dir. this config file
                    is required by all the scripts below.

signups_verify.py - reads players.csv from the game's data directory, validates
                    each row, uses players_email.csv as a species-to-email
                    fallback when needed, and appends the approved signup rows
                    into the game CSV only when the email is not already present
                    (for VFD, vallenfield.csv).

signups_fetch.py  - reads structured signup emails from the configured mailbox
                    and writes players.csv / players_email.csv for use with
                    game_setup.py. Use a subject containing "FH <game stub>
                    Signup" so it is distinct from normal turn mail. Common
                    prefixes like "Re:" and extra spacing are accepted. The
                    files are written into the matching game's data directory.

create_map.py     - Create a PDF map of the galaxy for the players.
                    also writes galaxy.map.txt from the same ListGalaxy output.

game_setup.py     - replaces Auto.pl. takes the csv generated by signups_fetch.py and
                    creates the game in the data directory by calling the appropriate
                    FH executables: NewGalaxy, MakeHomes, HomeSystem, AddSpecies,
                    then runs Finish/Report and renames first-turn reports to
                    spNN.rpt.t1.txt

game_packet.py   -  tool that creates a first turn packet zip file with galaxy maps,
                    turn reports, and policies files. It prefers game_policies.pdf,
                    then gameDocs/policies.txt if present.

orders_fetch.py   - replaces fhprocmail. fetches orders via imap from gmail and
                    verifies their accuracy, then sends a confirmation email.

orders_status.py  - prints out the status of all players' orders.
                    (errors, no orders, ready)

orders_clean.py   - cleans orders before processing. removes empty lines.

turn_run.py       - replaces fhtest. run this in the game directory to process a turn.
                    however, it doesn't save the turn results. it places them in a
                    tmp folder so you can verify them.

turn_confirm.py   - replaces fhsave. run from the game directory. copies the
                    turn results generated with turn_run into the game directory.
                    Renames report files to add .txt in the game directory.

turn_send.py      - replaces fhreports. sends an email containing the turns results
                    to all players. also notifies them of the next deadline.

turn_inject.py    - injects input (from stdin) into the beginning of all the turn reports.

turn_save.py      - replaces fhclean. saves the turn into backup/ and reports directory.

game_manager_gui.py - FreeSimpleGUI desktop app that runs game-management
                      tools and lets you browse/view game and turn files. Includes
                      a New Game Wizard for guided first-turn setup.
```

## GUI control panel

You can run a desktop GUI for end-to-end game management:

```
python3 game_manager_gui.py
```

The GUI can:

- run setup, orders, turn, and report tool commands
- run selected engine binaries
- view game and turn files directly from the game data directory
- stream command output in a built-in console panel
- provide a Player Ops tab for per-species status, reminder/send actions,
  and quick preview/open of orders and reports
- include player search filtering and turn-history dropdown selection in
   Player Ops for faster per-species workflows
- run an automatic startup preflight (plus manual re-run) to verify config,
   bindir/datadir, and engine probe readiness before running workflows

On Windows, tool execution now prefers native `.exe` binaries in `bindir`.
If only Linux ELF binaries are present, the tools will automatically try to
run them through WSL from the current game directory.

If WSL is present but no distribution is installed, commands will fail until
you install one (for example: `wsl --install -d Ubuntu`).

## Game setup

To prepare a new game of FH:

1. Ensure you've installed the dependencies listed above
2. Collect signups in a csv file (see example.csv for the format)
3. Edit your `farhorizons.yml`
4. Create the game: `python3 game_setup.py < your_signups.csv`
5. Create the maps: `python3 create_map.py`
6. (optional) Inject the game start intro text into the turns (see
   doc/intro.txt for the original FH intro)

   ```python3 turn_inject.py < path/to/intro.txt```

6. Create the first turn zip files: `python3 game_packet.py`

Send out your game packets, and off you go!

The first-turn reports are written as `spNN.rpt.t1.txt`, and `create_map.py`
also writes `galaxy.map.txt` alongside the PDFs.


## Running a turn

1. Add all the player's order files (with .ord extension) do your game's data
   directory
2. Run `python3 turn_run.py` It will output the results from the turn in a tmp
   dirctory.
3. Investigate this temp directory and ensure everything looks good.
4. (optional) If something isn't right, or you want to run it again, add the
   `--discard` flat to the `turn_run.py` command.
5. Then confirm the turn with `python3 turn_confirm.py`
6. Save the turn and create backup folders with `python3 turn_save.py`
